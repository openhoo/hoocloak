# Working on Hoocloak

Hoocloak is the local-development OIDC provider in this repository. Read
`CONTRIBUTING.md` for change and pull-request conventions.

## Agent skills

- For development of Hoocloak itself, read
  [hoocloak-development](skills/hoocloak-development/SKILL.md).
- For using Hoocloak in another application's local environment, read
  [hoocloak-integration](skills/hoocloak-integration/SKILL.md).

The development skill is also exposed through `.agents/skills`. Installable
skill sources live in `skills/`; keep the development discovery link relative.
Keep skill instructions aligned with source, package scripts, and CI when
changing the contracts they describe.
